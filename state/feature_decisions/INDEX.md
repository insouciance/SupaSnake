## Process Notes

### How to Use This Index

1. **Before coding:** Complete Feature Impact Template
2. **After decision:** Add entry to Active Decisions
3. **After implementation:** Move to Approved & Implemented with outcome notes
4. **If rejected:** Document in Rejected with reasoning

### File Naming Convention

Assessment files: `YYYY-MM-DD_[feature-slug].md`
Location: `state/feature_decisions/`

Example: `2025-01-22_collection-ui.md`

### Quarterly Review Process

- First week of each quarter
- Review constraints under pressure
- Update severity classifications if needed
- Document lessons learned
